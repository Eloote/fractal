## Описание проекта

Программа визуализирует фрактальное дерево с помощью рекурсивного
алгоритма. На каждой итерации из конца ветки строятся две новые ветки
меньшей длины под заданным углом.

## Функциональные возможности

- Отрисовка фрактального дерева
- Рекурсивное построение ветвей
- 10 уровней рекурсии
- Изменение угла ветвления
- Интерактивное управление параметрами

## Требования к системе

- Python 3
- tkinter
